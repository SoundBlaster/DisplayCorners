# Display Corners

Небольшое приложение для macOS 13 и новее, рисующее чёрные скругления на всех подключённых дисплеях. Управление — через значок в строке меню. Можно выключить эффект, отдельно выбрать верхние и нижние углы и изменить радиус. Настройки сохраняются. Интерфейс доступен на русском и английском языках и выбирается в соответствии с языковыми настройками macOS; для остальных языков используется английский.

Окна маски прозрачны для мыши и отображаются в Spaces и полноэкранных приложениях. Скругления — визуальная имитация: они закрывают часть изображения, не меняют физический дисплей и не деформируют окна. На LCD чёрный может отличаться от цвета рамки. Экран блокировки и некоторые системные поверхности могут показываться поверх маски.

На macOS 26 и новее приложение может показывать активность локальных сессий Codex в нижнем правом углу. Откройте **Agent Settings** в меню приложения и выберите **Install Hooks**, затем проверьте и разрешите hooks в самом Codex. Для удаления используйте **Remove Hooks**. Установка не изменяет другие hooks; доверие к ним определяется Codex отдельно. Обнаружение сессий неполное, состояние ожидания разрешения пока не поддерживается. Нажатие на доступную строку Codex открывает соответствующий чат в Codex Desktop, если клиент поддерживает этот переход. Если название чата недоступно, показывается нейтральная подпись.

## Сборка

Для сборки нужны Xcode Command Line Tools и Swift 6; готовому приложению они не требуются. Вызовите `./build.sh`: скрипт принимает необязательные переменные `BUILD_ROOT` и `SWIFTPM_CACHE`, чтобы вынести сборку и кэш за пределы проекта. `UNIVERSAL=1` собирает версии для Apple silicon и Intel. Результат — `Display Corners.app` в `BUILD_ROOT`. Если переменные не заданы, используются временный каталог и стандартный кэш SwiftPM.

Приложение подписывается локальной ad-hoc подписью; оно не нотарифицировано для распространения. Никакие разрешения Screen Recording и Accessibility не запрашиваются.
