# Display Corners

Небольшое приложение для macOS 13 и новее, рисующее чёрные скругления на всех подключённых дисплеях. Управление — через значок в строке меню. Можно выключить эффект, отдельно выбрать верхние и нижние углы и изменить радиус. Настройки сохраняются.

Окна маски прозрачны для мыши и отображаются в Spaces и полноэкранных приложениях. Скругления — визуальная имитация: они закрывают часть изображения, не меняют физический дисплей и не деформируют окна. На LCD чёрный может отличаться от цвета рамки. Экран блокировки и некоторые системные поверхности могут показываться поверх маски.

## Сборка

Нужны Xcode Command Line Tools и Swift 6. Вызовите `./build.sh`: скрипт принимает необязательные переменные `BUILD_ROOT` и `SWIFTPM_CACHE`, чтобы вынести сборку и кэш за пределы проекта. Результат — `Display Corners.app` в `BUILD_ROOT`. Если переменные не заданы, используются временный каталог и стандартный кэш SwiftPM.

Приложение подписывается локальной ad-hoc подписью; оно не нотарифицировано для распространения. Никакие разрешения Screen Recording и Accessibility не запрашиваются.
